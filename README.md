# Flappy Bird Revived

## Overview

Flappy Bird Revived is a simple arcade game inspired by the classic Flappy Bird.
The player controls a bird and navigates through obstacles by timing jumps.

The objective is to achieve the highest score by passing through as many pipes as possible.

---

## Gameplay

* Press a key to make the bird jump
* Avoid hitting pipes or the ground
* Each successful pass increases the score
* The game ends on collision

---

## Features

* Basic game loop implementation
* Collision detection
* Score tracking
* Simple graphics and controls

---

## Technologies Used

* Language: Java
* IDE: NetBeans

---

## Project Structure

* `src/` – Source code
* `build/` – Compiled files
* `dist/` – Executable JAR file

---

## How to Run

1. Clone the repository:

```bash id="runjava1"
git clone https://github.com/Hangle14204/Flappy-Bird-Revived.git
```

2. Open the project in NetBeans

3. Build and run the project

Or run the JAR file:

```bash id="runjava2"
java -jar dist/FlappyBirdRevived.jar
```
